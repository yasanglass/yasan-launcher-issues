# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue.

Instead, use GitHub's [private vulnerability reporting](https://github.com/yasanglass/yasan-launcher-issues/security/advisories/new) to send the details privately.

Include a description of the vulnerability, steps to reproduce it, its potential impact, and the affected YASAN Launcher version. Please avoid including personal data in reports, screenshots, or logs.

Allow a reasonable amount of time for the report to be investigated before disclosing it publicly.
