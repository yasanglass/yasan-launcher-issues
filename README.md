## Automation Bridge: setAppVisibility

New Automation Bridge command `setAppVisibility` supports global and
space-specific app visibility.

Parameters: `packageName` (required), `visible` (required), and optional `spaceId`.

Example: setAppVisibility(packageName, visible, spaceId?)
